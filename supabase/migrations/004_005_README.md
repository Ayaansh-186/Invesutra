# Monthly SIP Plans And Saved Reports

Run `004_monthly_sip_plans.sql` and then `005_saved_report_snapshots.sql` in the Supabase SQL editor before deploying this update. Both migrations can be rerun.

004 adds optional planned monthly contributions to holdings. These do not schedule payments or create transactions and are excluded from financial totals.

005 stores complete versioned report snapshots. Old reports remain available as saved summaries; missing historical details are not reconstructed from today's holdings. Reports that previously failed to save cannot be recovered from the database.
